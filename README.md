# 📂 Prompt Library — Google AI Studio

Repositório centralizado para armazenamento, organização e versionamento de prompts estruturados e avançados utilizados em engenharia de prompt e desenvolvimento de software com inteligência artificial.

---

## 🗂️ Estrutura do Repositório

Atualmente, o repositório conta com a seguinte organização por especialidade:

* `Senior-Front-End-Architect/` — Prompts focados em arquitetura de front-end, refatoração de interfaces, UI/UX, Design Systems com tokens CSS e padrões rígidos (React 18, TypeScript, Material UI).

---

## 🚀 Como Utilizar

1. Navegue até a pasta da categoria desejada (ex: `Senior-Front-End-Architect`).
2. Copie o prompt estruturado.
3. Cole na sua ferramenta de IA (como o Google AI Studio ou Claude) junto com o contexto ou trecho de código específico que deseja resolver.
