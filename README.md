# 📂 Prompt Library — Google AI Studio

Repositório centralizado para armazenamento, organização e versionamento de prompts estruturados e avançados utilizados em engenharia de prompt e desenvolvimento de software com inteligência artificial.

---

## 🗂️ Estrutura do Repositório

Atualmente, o repositório conta com a seguinte organização por especialidade:

* **`Senior-Front-End-Architect/`** — Prompts para arquitetura de front-end, refatoração completa, convenções de código, integração com backend e padrões estritos (React 18, TypeScript, TanStack Query, Material UI sem Tailwind).
* **`Responsiveness-Expert/`** — Prompts focados em adaptação multi-telas, layouts responsivos, suporte a Smart POS / Terminais Android (<= 480px), conversão automática de tabelas para cards e acessibilidade móvel.
* **`Motion-Design-Specialist/`** — Prompts focados em microinterações, transições fluídas com `motion/react`, estados interativos (hover/active), animações não bloqueantes e suporte a movimento reduzido (`useReducedMotion`).
* **`UI-UX-Specialist/`** — Prompts voltados para melhorias de usabilidade, hierarquia visual, clareza de formulários, fluxo operacional rápido para estacionamentos e polimento estético (Visual Polish).

---

## 🚀 Como Utilizar

1. Navegue até a pasta da especialidade desejada no repositório.
2. Copie o prompt estruturado no idioma de sua preferência (`.md`).
3. Cole no **Google AI Studio** (ou no modelo de sua preferência) e adicione o trecho de código ou componente que deseja refatorar no final.
